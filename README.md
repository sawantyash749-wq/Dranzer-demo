# Student Management System

A beginner-level SQL project built using MySQL to manage and analyze student information.

## Database

The project uses a `STUDENTS` table containing student details such as:

- NAME
- AGE
- CITY
- COURSE
- MARKS

## SQL Concepts Used

- SELECT
- WHERE
- MAX()
- MIN()
- AVG()
- COUNT()
- ORDER BY
- GROUP BY

## Queries Included

The project performs queries to:

- Find students from a specific city
- Find the highest marks
- Find the lowest marks
- Calculate average marks
- Count the number of students
- Sort students by marks
- Count students in each course
- Find students above a certain age
- Find students with specific marks
